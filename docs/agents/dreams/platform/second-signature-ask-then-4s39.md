# Second signature: ask for his next wallet, then 4S39

## Situation

A mainnet action Alex McRitchie had asked for needed one more signature than his first
wallet gave. He was asked which key should supply it.

## The pull

Reach for whichever key is nearest: the agent governance seat he also holds a
copy of, a key from an older signer set, or the server key on the agent's own
judgment. Or describe the choice in the negative ("don't use 9gAC") and leave him
to work out which wallet to open.

## What happened

Alex McRitchie answered in chat on 2026-10-15: "I think it's more effective to always say
use this (the other address), maybe we can just add a dream about when a second
signature is needed, you can go ahead and use 4S39 in a pinch." He then said
"Yes" to the scope: the server key signs as the second signature only on an
action he asked for in that session, never on an agent's own initiative. His
wallet order is 7ZDJ, 3Qj4, 9gAC, and the agent names the one to use ("switch to
3Qj4"). 3LTL is an agent seat; his copy is break-glass. The rule is First Rule
10; the detail is `squad-vault-ops`, section *The second signature*.
