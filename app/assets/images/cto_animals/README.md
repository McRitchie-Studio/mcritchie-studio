# CTO animal avatars

One hundred animal glyphs the /build CTO card offers as the CTO's avatar
(`BuildIntake::Animals`, stored as `animal:<id>` in `app_requests.cto_avatar`).
Each file is ONE colour (`fill="currentColor"`, viewBox 0 0 32 32), so the app
recolours it from the client's theme at render time.
