# Build documents from the kit

## Situation

Alex McRitchie asks for a document: an agreement, a letter, a policy, a memo. He may
name a template loosely, or name none. The business it serves is usually clear
from the conversation.

## The pull

Write a Word file locally. It is fast, the tooling is at hand, and the file looks
finished. A search of local folders that finds no template feels like proof that
none exists.

## What happened

A session asked for three agreements on "the template" searched local files and
mail, reported that no template existed, and built Word files on a letterhead from
a signed letter. The kit's General template was in Drive the whole time, in
`05 Templates`. When Alex McRitchie asked for a URL, the session could offer only
links that opened on one Mac. He then set the rule: find the context, start from the
Marketing Kit template, and deliver an editable, shareable master in Drive. A
**doc master** is that Google Doc. A test on 2026-11-04 proved that a shortcut opens
the one master and grants no access. Where it lives and how others reach it are in
[`one-master-and-shortcuts`](one-master-and-shortcuts.md) and the
[`marketing-kit`](../../agents/alex/sops/marketing-kit.md#doc-masters) SOP.
