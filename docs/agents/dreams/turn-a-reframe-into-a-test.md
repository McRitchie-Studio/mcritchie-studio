# Turn a reframe into a test

## Situation

A discussion about an agent wallet stalled until Alex called the key a system credential, not an identity.

## The pull

Say 'good point' and carry on with the wallet design.

## What happened

Asked what the reframe implied (system credentials are per-environment), checked every credential against it, and found one signing key shared between production and QA.
