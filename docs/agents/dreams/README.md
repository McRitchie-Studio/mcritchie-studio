# The dream bank

One file per dream: a worked decision from a past session. Approved dreams load
into every new session at start. The procedure, the format and the sign-off rule
are in [`../modules/dream.md`](../modules/dream.md).

- `status: proposed` is a candidate waiting for Alex. It loads nowhere.
- `status: approved` is signed off by Alex. It loads everywhere.

This file is the bank's own page. The loader skips it.
